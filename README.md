# ETHOS Industrial — interface GitHub Pages

Esta pasta contém **apenas a interface pública**, sem dados de produção, sem credenciais administrativas e sem SQLite. Configure `firebase-config.js` com os dados **públicos** do aplicativo Web Firebase antes de publicar.

O Firebase Authentication e o Cloud Firestore exigem regras de segurança publicadas separadamente. O tutorial completo acompanha o pacote de instalação **fora** desta pasta. Nunca envie dados de produção, arquivos JSON de contas de serviço, bancos de dados ou senhas para o repositório.
